# Hotel Room Booking System

A web app for booking hotel rooms. Guests can search for available rooms, book them and manage their reservations. Admins manage rooms and see all bookings.

## Team

| Member | Role     | Worked on                                       |
|--------|----------|-------------------------------------------------|
| Rio    | Backend  | Login/register, room management, dates, booking |
| Ahti   | Frontend | Frontpage, AdminView, UserView                  |
| Joni   | Database | Database schema                                 |

## Tech

- **Frontend:** React, TypeScript, Vite, Tailwind CSS
- **Backend:** Node.js, Express
- **Database:** MariaDB
- **Tools:** Git/GitHub

## Features

- Register and login (hashed passwords, user and admin roles)
- Admin: add, edit and delete rooms, set availability dates, see all bookings
- Guests: search available rooms, book with dates, guests and special request, see the total price, cancel reservations
- Double bookings are prevented
